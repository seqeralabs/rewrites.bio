# Manifesto Reader

Read the rewrites.bio manifesto in markdown and navigate its principles.

## When to use

Use when an agent needs the full manifesto text or a specific principle without parsing HTML.

## Resources

- Markdown: `https://rewrites.bio/manifesto.md`
- Homepage: `https://rewrites.bio/` — serves HTML to browsers, and markdown to clients that send `Accept: text/markdown`
- Agent instructions: `https://rewrites.bio/.well-known/agent.md`

## Sections

1. Introduction — opportunity and risk of AI-assisted rewrites
2. Philosophy — credit authors, emulate exactly, transparent AI
3. Planning — think big, work small
4. Building — test/benchmark, build only what you need, pin versions
5. Stewardship — maintain, preserve compatibility, open source, contribute upstream
